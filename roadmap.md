# Roadmap — PharmaField (field sales, inventory, delivery & collection)

## Phase 1 (this build)
- [ ] Cloud backend: roles, settings, products, batches, locations, stock ledger, requisitions, chemists, doctors, orders, deliveries, collections, wallet ledger, deposits, visits, audit, notifications
- [ ] Sign-in (email, Google, Lovable) + role-gated app shell
- [ ] Dashboard (admin KPIs + SO home)
- [ ] Products & pricing policy settings
- [ ] Central/SO inventory, stock receipt, CSV bulk opening stock, adjustments, ledger
- [ ] Requisitions (submit → approve/partial → issue FEFO → receive)
- [ ] Chemists & doctors with duplicate detection
- [ ] Orders with live pricing, discount limits & approval
- [ ] Full/partial delivery + printable challan
- [ ] Full/partial collection, SO wallet, deposits with proof upload, finance approval, receipt
- [ ] Doctor visits with promo stock issue
- [ ] Reports with CSV export, users & roles, audit log, notifications

## Later
- Expenses module
- Offline order drafts / mutation queue
- PDF exports (server-generated), SMS/push adapters
- Barcode/DataMatrix scanning, recall workflow, GPS rules
